# HeronPanel Official

HeronPanel® — The free game server control panel for users, networks, and game service providers.

HeronPanel is a modern Minecraft server management panel with a real Node.js backend, real server folders, Paper server version selection, live console, file manager, plugin/mod installer, player management, coins system, marketplace, and admin controls.

## Features

- Real Node.js backend
- Login and register system
- Admin account and user accounts
- Coins system
- Server creation system
- Marketplace server limit upgrade
- Real Paper `server.jar` download and run
- Paper version selector from `1.19` to latest
- Live console output from the server process
- Start, stop, and restart controls
- Console command sender
- File manager
- File editor with save loading state
- File and folder upload
- ZIP browser and extractor
- Plugin installer
- Mod installer
- Online plugin/mod search with Modrinth and Spiget
- Player management
- Whitelist, OP, kick, ban, and remove actions
- Server icon upload
- Custom MOTD
- Network port management
- Database, schedules, users, backups, startup settings
- Black and white premium panel theme

## Requirements

Install these before running HeronPanel:

- Node.js 18 or newer
- Java 17 or Java 21
- Internet connection for first Paper server download

Latest Paper versions usually require Java 21. Older Paper versions such as 1.19 usually work with Java 17.
