# Research Notes

## Pterodactyl-Inspired Controls

- Servers: list servers, open details, inspect resources and status.
- Power: start, stop, restart and kill server processes.
- Console: read live output and send commands.
- Files: list, read, upload, download, create folders, delete, copy, rename and compress.
- Databases: list, create, rotate password and delete.
- Schedules: create cron-style tasks and execute command, power or backup tasks.
- Network: view allocations, assign extra ports, set primary allocation and add notes.
- Users: invite subusers and apply permissions.
- Backups: list, create, download, restore and delete.
- Startup: command, image/runtime and environment variables.

Source: https://pterodactyl-api-docs.netvpx.com/docs/api/client

## Aternos-Inspired Controls

- Start: starts the server.
- Stop/Restart: stops or restarts the server.
- Console: opens logs and allows commands.
- Log: view and share the log.
- Options: slots, gamemode, difficulty, whitelist, cracked mode, PVP, command blocks, fly, mobs, nether and timezone.
- Software: switch server software.
- Players: manage whitelist and OP list.
- Files: browse/edit/delete allowed files and remove plugins/mods.
- Plugins/Mods: install content from a catalog.
- Worlds: upload/download/regenerate worlds.
- Backups: create, restore and configure automatic backups.
- Access: share server permissions with trusted users.
